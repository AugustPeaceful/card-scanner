⚡ Как это работает

Приложение использует Claude (claude.ai) для распознавания — тот же чат где ты сейчас. Никаких дополнительных оплат. Ты уже платишь подписку — используй её.

📱 Шаги каждый раз

1. Вкладка Сканер
2. Нажми "Открыть Claude"
3. В claude.ai прикрепи фото 📎 и отправь с скопированным промптом
4. Скопируй JSON из ответа
5. Вернись сюда → вставь → "Разобрать"
6. Проверь поля → "Добавить"

💡 Советы

• Фото должно быть чётким и с хорошим освещением
• Если на фото несколько визиток — Claude разберёт все
• Рукописные заметки попадают в поле "Заметки"
• Японский, корейский, русский — всё распознаётся

💾 Данные

Все контакты хранятся на твоём телефоне. Экспортируй в CSV или JSON в любой момент.

🔗 Добавить на экран

Открой в Safari → Поделиться → На экран «Домой» — и приложение будет как нативное.
